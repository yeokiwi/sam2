# Enhanced Contour Plotting with Mask Visualization

## Overview

The `show_mask` function in `image.py` has been enhanced to provide flexible visualization of simplified contours together with mask overlays. The implementation allows users to display polygon-approximated contours as clear matplotlib lines and markers while maintaining the mask overlay.

## Key Features

### 1. **Enhanced Contour Visualization**
   - Simplified contours are plotted as red lines (`'r-'`) with thickness 3
   - Polygon vertices are marked as blue dots for easy identification
   - Lines are closed polygons (first point connected to last point)
   - High visibility with alpha blending (alpha=0.8)

### 2. **Flexible Display Options**
   - **`borders=True`**: Draws OpenCV contours on the mask image (green borders)
   - **`plot_contours=True`**: Plots matplotlib lines and markers (red lines, blue dots)
   - **`epsilon` parameter**: Controls polygon simplification strength
   - **`save_contours=True`**: Saves simplified contours to CSV files

### 3. **Backward Compatibility**
   - Existing code continues to work unchanged
   - Default behavior: `borders=True`, `plot_contours=True`
   - All existing parameters remain supported

## Usage Examples

### Basic Usage
```python
# Default: borders + contour plotting
show_mask(mask, ax, borders=True, plot_contours=True, epsilon=5.0)

# Contour plotting only (no OpenCV borders)
show_mask(mask, ax, borders=False, plot_contours=True, epsilon=2.0)

# OpenCV borders only (no matplotlib plotting)
show_mask(mask, ax, borders=True, plot_contours=False, epsilon=5.0)

# Save contours to CSV
show_mask(mask, ax, borders=True, plot_contours=True, 
          save_contours=True, contour_output_dir="contours", epsilon=10.0)
```

### In the Main Pipeline
```python
# In show_masks function (already integrated)
show_masks(image, masks, scores, borders=True, save_contours=True, 
           contour_output_dir="contours", epsilon=10.0)
```

## Visual Elements

1. **Mask Overlay**: Semi-transparent color overlay (default: red tint with alpha=0.6)
2. **OpenCV Borders**: Green borders drawn directly on mask image (when `borders=True`)
3. **Matplotlib Contours**: 
   - Red solid lines connecting polygon vertices
   - Blue dots at each vertex point
   - Closed polygons (first and last points connected)

## CSV Output

When `save_contours=True`, simplified contours are saved as CSV files:
- **Format**: `contour_{timestamp}_{index}.csv`
- **Columns**: `x`, `y` (pixel coordinates)
- **Content**: Polygon vertices in order (closed polygon)

## Performance Benefits

1. **Reduced Complexity**: Polygon approximation reduces point count significantly
2. **Cleaner Visualization**: Matplotlib lines are cleaner than pixel-based borders
3. **Flexible Control**: Separate control over borders and contour plotting
4. **Data Export**: Simplified polygons can be exported for downstream processing

## Example Output

With `epsilon=10.0` on a complex mask:
- Original contour: 274 points
- Simplified contour: 8 points (97% reduction)
- Visual appearance: Clean polygon with clear vertices

## Integration with SAM2

The enhanced visualization works seamlessly with the SAM2 pipeline:
1. Masks are generated by SAM2 predictor
2. Contours are extracted and simplified
3. Simplified contours are displayed with mask overlay
4. Contours can be saved for further analysis

## Notes

- The `plot_contours` parameter defaults to `True` for maximum visibility
- Different epsilon values produce different simplification levels
- CSV files contain the simplified polygon vertices, not the original dense contours
- Both OpenCV borders and matplotlib plotting can be used together for layered visualization
